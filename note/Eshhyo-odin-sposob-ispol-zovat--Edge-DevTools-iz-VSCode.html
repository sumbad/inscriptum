Ещё один способ использовать Edge DevTools из VSCode

Если вы разрабатываете веб-приложение в VS Code, необязательно переключаться между редактором и браузером, чтобы открыть DevTools.

Расширение Microsoft Edge Tools for VS Code позволяет запускать Edge и использовать DevTools прямо внутри VS Code.

  1. Устанавливаем расширение (или из исходников https://github.com/Microsoft/vscode-edge-devtools).

  2. Добавляем конфиг launch.json:

{
    "version": "0.2.0",
    "configurations": [
        {
            "type": "vscode-edge-devtools.debug",
            "request": "launch",
            "name": "Launch Microsoft Edge and open DevTools",
            "url": "http://localhost:8081/",
            "webRoot": "${workspaceFolder}"
        }
    ]
}
JSON

В примере выше приложение будет запущено на http://localhost:8081 .

  1. Запускаем приложение и далее Debugger:

При этом должна открыться страница с url указанным в конфигурации.

  1. Запускаем расширение Open Browser Devtools.

Это приводит к открытию Devtools, который относится к ранее запущенному приложению.

Теперь можно отлаживать код в браузере прямо из VSCode.

Примечание: Если Edge уже запущен в режиме удалённой отладки, вместо launch можно использовать attach:

{
    "type": "vscode-edge-devtools.debug",
    "request": "attach",
    "name": "Attach to Microsoft Edge and open DevTools",
    "url": "http://localhost:8081/",
    "webRoot": "${workspaceFolder}"
}
JSON

Таким образом, расширение подходит как для запуска нового экземпляра Edge, так и для подключения к уже работающему браузеру.
